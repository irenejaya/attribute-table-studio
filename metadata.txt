about=GeoTable Studio adds three tools to one QGIS toolbar.
    Attribute Explorer - a fast, read-only attribute table with exact column statistics attached above every column (missing and distinct counts, top categories, histograms, date ranges), an always-visible typed filter under every heading, map selection sync, column layouts saved per layer, and CSV / Excel export with the scope recorded.
    Pivot Table - grouped summaries and cross tabs with multiple measures (count, count distinct, sum, mean, median, min, max, standard deviation), correct totals calculated from records, an explicit input scope (all, Explorer filtered or selected records) with stale detection, drill-through to the contributing records, saved layouts, and CSV / Excel / GeoPackage export.
    Geometry and Table Compare - visual OLD -> NEW comparison of two dataset versions: added, deleted, modified and unchanged features, field-level old -> new values, exact geometry comparison with review points for multipart features, validation, accept / reject review and Excel / CSV export.
    Every tool opens in its own window and can be docked into QGIS like the native attribute table; the look follows the QGIS light or dark theme.
