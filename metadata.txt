description=Explore, summarise, plot and compare vector attribute tables: Attribute Explorer, Pivot Table, Data Plot, and Geometry and Table Compare in one toolbar.
about=Attribute Table Studio is an advanced version of QGIS Attribute Table and can do more. This tool consist of four tools to one QGIS toolbar.
    <b>Attribute Explorer</b> - a fast attribute table with exact column statistics attached above every column (missing and distinct counts, top categories, histograms, date ranges), an always-visible typed filter under every heading, an editing mode sharing the layer's edit session (QGIS cell editors and forms, constraints, field calculator, quick update, multi edit, add / delete / clipboard, new and virtual fields), table and form views, scopes, expression filters, map selection sync, column layouts saved per layer, and CSV / Excel export with the scope recorded.
    <b>Pivot Table</b> - grouped summaries and cross tabs with multiple measures (count, count distinct, sum, mean, median, min, max, standard deviation), correct totals calculated from records, an explicit input scope (all, Explorer filtered or selected records) with stale detection, drill-through to the contributing records, saved layouts, and CSV / Excel / GeoPackage export.
    <b>Data Plot</b> - plots of a layer's records with the twelve chart types of ArcGIS Pro (bar, line, combo, pie, histogram, box plot, scatter plot, scatter plot matrix, QQ plot, data clock, calendar heat chart, matrix heat chart) and their options: time binning, split by, trend lines, statistics and guides on the chart, class breaks and colour ramps; live records (all, Explorer filtered, selected or the map extent), selection both ways, plots saved per layer in the project, and PNG / SVG / CSV export.
    <b>Geometry and Table Compare</b> - visual OLD -> NEW comparison of two dataset versions: added, deleted, modified and unchanged features, field-level old -> new values, exact geometry comparison with review points for multipart features, validation, accept / reject review and Excel / CSV export.
    Every tool opens in its own window and can be docked into QGIS like the native attribute table; the look follows the QGIS light or dark theme.
